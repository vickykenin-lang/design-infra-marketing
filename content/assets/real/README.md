# Real Design Infra project photos

Drop finished project photos here. The weekly image job (`scripts/fetch_images.py`) will register them automatically as **real_project** (no “Concept visualisation” badge).

## Naming (recommended)

- `living-1.jpg`, `living-2.jpg`
- `kitchen-1.jpg`
- `bedroom-1.jpg`
- `bathroom-1.jpg`
- `office-1.jpg`

Any `.jpg` / `.jpeg` / `.png` / `.webp` works. Room type is inferred from the filename when possible.

## Rules

- Only **completed Design Infra work** (or work you own the rights to show).
- Prefer bright, clean, mid-premium shots suitable for Instagram.
- These override free-stock and AI concept images for conversion.
